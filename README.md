Grama-Urja (Energy)

 Overview

Grama-Urja is an Android application designed to help farmers in rural areas track electricity availability in real time. The app uses community-powered updates to notify users when power is ON or OFF in their transformer zone, helping reduce unnecessary travel and improve irrigation planning.

 Problem Statement

In rural areas, power cuts are frequent and unpredictable. Farmers often walk long distances to check whether electricity is available to operate irrigation pumps. This results in wasted time, effort, and inefficient water management.



 Solution

Grama-Urja provides a crowdsourced power monitoring system where users can:

 Update power availability status
 Receive alerts when power returns
 Monitor the latest power updates in their area
 Use a pump timer for irrigation planning

The application helps create a community-driven smart energy monitoring system.



 Features

 Real-Time Power Status

Users can mark whether power is ON or OFF in their transformer zone.

 Community Updates

Power availability is updated collectively by users in the same area.

 Alerts & Notifications

Users receive instant notifications whenever the power status changes.

 Pump Timer

A built-in timer helps farmers estimate irrigation duration based on crop needs.

 Last Seen Status

Displays the latest power update timestamp.
